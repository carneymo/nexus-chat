## Samsung USB test

Connect one phone with a data-capable cable, enable USB debugging and accept the PC authorization prompt. From the repository root, run:

```powershell
./android/scripts/install.ps1
```

The installer checks the APK checksum, installs over an existing compatible version without clearing its data, and launches Nexus. Sign in on the phone; passwords do not need to be shared with the assistant.

Verify sign-in/reopen, keyboard visibility, channel messages, whispers, image selection, Wi-Fi/mobile reconnection, and two-way foreground voice using a second account. Locking the phone or backgrounding the app should release the microphone. Draft recovery and updated deep-link behavior require deploying the accompanying frontend. Notifications require Firebase plus the backend deployment. See `android/README.md` for the full acceptance checklist.
